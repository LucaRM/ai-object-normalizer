REST API Usage Reference

You can call this API directly in your backend cascade pipeline (e.g. from luca-app or background workers):

POST /normalize
curl -X POST http://localhost:3009/normalize \
  -H "Content-Type: application/json" \
  -d '{
    "template": "monster",
    "text": "Tiger\nLarge Beast, Unaligned\nArmor Class 13...",
    "autoSplit": true,
    "options": {
      "targetLocale": "pt-BR",
      "format": "all"
    }
  }'
POST /preprocess
curl -X POST http://localhost:3009/preprocess \
  -H "Content-Type: application/json" \
  -d '{
    "text": "[Ankheg](url)\nLarge Monstrosity...\n\n[Animated Armor](url)..."
  }'
// Returns: { count: 2, entities: [ { name: "Ankheg", ... }, ... ] }
POST /normalize/batch
curl -X POST http://localhost:3009/normalize/batch \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      { "template": "monster", "text": "Tiger...", "options": { "targetLocale": "pt-BR" } },
      { "template": "monster", "text": "Lion...", "options": { "targetLocale": "pt-BR" } }
    ]
  }'
